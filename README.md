This repo contains the openFOAM files and data processing python files to run and process data for aerosol particles. 
Main focus is on modelling particle transport in a sampling line and studying the particle ramp up at the outlet.

Step Up:
This is where scripts for processing the simulation data for the particle step-up case is located. 

Silicone_tube_loss_scalar_transport:
This is the openfoam folder in which the CFD is ran.
